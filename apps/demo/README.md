# Streamweld website

The static project website published at [streamweld.vercel.app](https://streamweld.vercel.app/).

From the repository root:

```sh
pnpm --filter @streamweld/website dev
```

The directory retains its historical path so the existing Vercel project root
continues to deploy without an external configuration change. The site is
static and contains no application APIs or persistent state.
