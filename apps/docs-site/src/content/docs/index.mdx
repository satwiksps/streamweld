## A small durability layer, not another model gateway

<CardGrid>
	<Card title="Reader resume" icon="refresh">
		Reconnect with the stream ID and exact last event ID. Already-delivered chunks stay delivered exactly once.
	</Card>
	<Card title="Producer migration" icon="seti:config">
		Continue on an eligible backend only when chat-template probes and runtime safety predicates say the seam is safe.
	</Card>
	<Card title="Explicit stop" icon="stop">
		Stopping generation is a protocol operation. Dropping a socket only detaches the reader.
	</Card>
</CardGrid>

The OpenAI-compatible proxy handles the data plane. A Kubernetes operator tracks
eligible backends, drains rollouts, and distributes route snapshots without
restarting the proxy.

```text
client ──SSE──▶ proxy ──▶ backend A ✕
                  │            │
                  ▼            └── journaled prefix
             append-only              │
               journal                ▼
                  │              backend B ──▶ same stream
                  └── exact replay cursor ──▶ reconnected reader
```

## Start with evidence

The deterministic failure matrix checks the entire output, not merely the HTTP
status. The committed local profile covers nine fault shapes; nightly CI repeats
the physical Kubernetes scenarios on kind. Timing figures are scoped to the host
and profile that produced them.

:::caution[Know the boundary]
Streamweld can continue a generation only when the request shape, token budget,
model version, and chat template make continuation safe. It deliberately refuses
unsafe migrations. It does not make sampling bit-for-bit deterministic, replace a
model scheduler, or provide an authentication and billing gateway.
:::
