# Benchmark artifacts

`results.json` is the machine-readable source and `results.md` is its canonical rendering. Both are generated by `make bench`; `make bench-check` rejects manual drift, missing scenarios, partial injections, invalid counters, or any false correctness result.

The committed default is the honestly labelled `deterministic-local` model/simulation profile. Its TTFT values come from paired direct-backend and in-process Streamweld HTTP requests made during that run. Its failure counters do not claim Kubernetes process disruption. They are not portable performance claims and are not used as CI thresholds. The scheduled workflow also runs the non-skippable kind profile as the physical injection gate and uploads its separately generated artifacts.

The `generated_at`, Go toolchain, operating system, architecture, concurrency, token count, backend, and execution mode are recorded so results cannot be mistaken for measurements from a different environment.
